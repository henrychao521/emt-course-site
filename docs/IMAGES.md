# 第四章操作示意圖：圖單、動作依據與驗收紀錄（2026-09-29）

流程：先從權威教材確認動作 → 寫檢核表 → AI 生寫實底圖（Antigravity `generate_image`）→ 本機 PIL 合成中文標註 → 人工逐項驗收（放大看）→ 不合格同名重生，不修圖。
拓樸／順序類與 AI 三次都畫不對的手勢改用程式繪製 SVG。教材原圖沒有拿來當生圖參考。

- 提示詞與檢核表：`tools/img/image_spec.py`（IMAGES／BASIS／CHECK）
- 生圖驅動器：`tools/img/gen_images.py`（軌跡在 `tools/img/traces/`）；AI 原圖：`images/ai-raw/`（不覆寫，重生檔名帶時間戳）
- 合成：`tools/img/compose.py`（APPROVED 指定採用哪張原圖）；SVG：`tools/img/diagrams.py`；插入頁面：`tools/img/insert_figures.py`
- 網頁輸出：`assets/img/*.webp`，1100×614，六張合計約 272 KB（單頁 < 600 KB）
